# Site watch (Course 804, lesson 3.3)

Ads make a promise and the page has to keep it. That's congruency. Pages change without anyone telling the strategist: a promotion ends, a price moves, a competitor launches a bundle. This skill checks a page on a schedule and reports when the offer, the price or the promise changes.

## Set up (first run)
Ask for:
- the pages to watch. For your own brand, every landing page a live ad points to. For a competitor, the home page and one or two product pages
- whether this is the user's own brand or a competitor
- how often to check (weekly fits the performance review, daily fits a promotion period)
- where the report goes (chat, one Slack channel, an email draft)

Read each page once and save what you find as the starting record. Show it to the user and **wait for approval before scheduling anything**.

## What to record for each page
Three things, as text:

| | What to write down |
|---|---|
| The offer | Promotions, bundles, free gifts, shipping and guarantee lines, any end date |
| The price | Every price shown: one-time, subscription, bundle, crossed-out |
| The promise | The headline, the subhead, the main claims and the CTA wording |

Add anything broken or missing. Save to `03-research/competitors/site-watch/<site>/<YYYY-MM-DD>.md`, with a screenshot next to it if the tool can take one.

## Each run
1. Read the same pages, in the same way as last time.
2. Record the offer, the price and the promise.
3. Compare with the last record. Report a change only when you can show the old value and the new value.

## The report
- Lead with what changed: `page | what | old → new`.
- If nothing changed, say "No change to the offer, the price or the promise."
- For the user's own brand, add **"Ads that may now be out of date"**: any live ad whose promise, price or offer (from `06-pipeline/launch-sheets/`) no longer matches the page. Flag it. Don't touch the ads.
- For a competitor, add one line on what the change might mean, labeled as a read. Remember: "Just because an ad is running doesn't mean it's working." The same goes for an offer.
- One line on any page you couldn't read.

## As a scheduled run
Put it on the sprint calendar (lesson 1.6 shows how; the app feature is called Routines). Give the run a browser and the one channel it reports to, nothing else. Send the report even when nothing changed, so silence never means it broke.

**Agents prepare. People approve.** The run posts only to the one channel a person set up for it. Everything else it writes stays in the Creative OS.

## Never
- Check out, log in, submit forms, sign up to lists or enter any personal or payment details.
- Copy a competitor's page text or design into the brand's work. Research to inspire, not to copy.
- Report a change you can't show.
