# Variation plays

A variation keeps what the strategist liked and makes a real change, so the platform sees a different ad and we learn something new. Default: 2 variations per keeper. Each variation gets its own hypothesis line.

| Play | What changes | When to use |
|---|---|---|
| Persona swap | Headline and visual cues rebuilt for a different micro persona | The angle is strong. Find who else it speaks to |
| Ad type swap | Same message in a different static ad type (for example key benefits → notes app) | Strong message, and you want a different look in the feed |
| Point of view swap | Brand voice → customer voice → expert voice | The message is right, the speaker could be more trusted |
| Proof swap | A different review, stat or piece of social proof, with its source ID | Same idea, different evidence |
| 9:16 rebuild | 4:5 → 9:16, laid out again for the placement, not cropped | Every keeper, before launch |

## The test
**If the platform would see two ads as the same ad, it is not a variation.** A changed word, a color tweak or a moved logo doesn't count. That is the similarity penalty at work. Go for bigger visual swings.

A 9:16 rebuild is a placement version, not a new test. Don't count it toward the two variations.
