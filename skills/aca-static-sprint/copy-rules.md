# Static copy rules

Read `corrections-log.md` first. It overrides this file.

## Where a headline comes from
Work in this order for every ad:
1. **Start from copy mining.** Open `03-research/audience/customer-voice.md` and go to the quotes sorted by emotion. The customer's words beat ours.
2. **Take the angle from the matrix row.** The row in `04-concepts/concept-matrix.md` names the persona, the angle and the awareness level. Use quotes from that angle's emotion group and that persona's micro persona sheet.
3. **One idea per ad.** If the headline needs "and", it's two ads.
4. **Grade 5 reading level.** Short words, short sentences. Contractions are fine.
5. **Structure from the ad type reference, never its words.** The reference in the swipe file tells you the layout and how long each line can be (`copy_slots`). Its wording stays out.

## Writing rules
- Specific beats clever. A moment, a number of hours, a place.
- Write for the awareness level on the row:

| Awareness level | The copy's job |
|---|---|
| Unaware | Educate or entertain, and point to the problem |
| Problem aware | Name the problem in their words |
| Solution aware | Show how the product solves it |
| Product aware | Give proof |
| Most aware | Make the offer, and give a reason to act now |

- Match the point of view. Brand voice speaks as the brand. Customer voice is a quote with a source ID. Expert voice needs a real expert the brand can name.

## Never
- Claims the brand can't prove (see `01-brand/dos-and-donts.md`).
- Fear-based health claims.
- Out-of-stock products, or discounts the brand doesn't allow.
- Empty phrases: "elevate", "unlock", "say goodbye to".
