# Corrections log

Every correction that should apply to future runs. Newest first. The static sprint reads this every run, and it overrides everything else. Notes ticked "always" on the gut check board land here.

- YYYY-MM-DD: <rule>, for example "Never place the logo bottom-right on reference S07. It collides with the CTA bar."

# Change log

What went out and when, so the next run knows what is still too early to call. Newest first. The sprint adds a line at hand-off and whenever the user says an ad was launched, paused or swapped.

- YYYY-MM-DD: <what changed>, for example "Batch evergreen-03 (18 ads) handed to the media buyer." / "Launched 2026-11-12." / "Check results on or after 2026-11-19."
