# Play: list or how-to

**What it does:** Opens by promising a list or a way to do something.
**Choose it when:** There are several real reasons, steps or tips for this persona.
**Don't choose it when:** There is only one point to make.

## Steps
1. Name the number or the task up front ("Three things nobody tells you about...").
2. Every item must be true and come from the Creative OS.
3. Show the first item on screen inside the first three seconds.

## Checks
- The count in the hook matches the count in the body.
- Plain words. A 10-year-old could follow it.
