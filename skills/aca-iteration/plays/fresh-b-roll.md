# Play: fresh B-roll

**What it does:** Recycles a winner with new visuals over the same audio.
**Choose it when:** A winner is starting to fatigue and the audio still works.
**Don't choose it when:** The message itself is tired.

## Steps
1. Keep the audio track as it is.
2. List the existing B-roll and unused footage in `05-production/`. Use the shot list database in `02-language/shot-list.md` if there is one.
3. Plan new visuals beat by beat. Change the first frame for sure.
4. If there isn't enough footage, list the shots to film.

## Output
A beat table (`audio line | old visual | new visual | footage source`) and the iteration brief.

## Checks
- No empty frames.
- The opening looks clearly different from the original.
