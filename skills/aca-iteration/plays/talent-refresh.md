# Play: talent refresh

**What it does:** Same script, different people. Part of the three-part winner playbook.
**Choose it when:** The script is proven under the team's win criteria.
**Don't choose it when:** The script hasn't earned it yet.

## Steps
1. Keep the script exactly as it is.
2. Plan for **at least five** different people for a proven script.
3. Cast to persona. Take the creator types from the micro persona sheets, and describe them by situation and content, not personal attributes.
4. Check the tracker in `05-production/creators/` for creators who already agreed. Use `aca-casting` for more.
5. Let each person's setting be their own. That makes the visuals different.

## Output
A casting list and the iteration brief. Suggest `aca-creator-brief` with the script marked as fixed.

## Checks
- Usage rights for image and voice are confirmed by a person for each creator.
