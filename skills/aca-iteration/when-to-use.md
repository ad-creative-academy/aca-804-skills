# When to use each play

Choose by two things: what the readout says about the ad, and what is cheap to make from what we already have.

## By what the readout says
| If the readout says... | Choose | Don't choose it when... |
|---|---|---|
| Strong story (good hold rate, good conversion), weak hook rate | `new-hooks` | The body is also weak. Then it's a new concept, not an iteration |
| A winner you want to reach a new audience with | `new-hooks` | |
| A winner starting to fatigue, and the audio still works | `fresh-b-roll` | The fatigue is in the message, not the visuals |
| A proven script, and the face has been seen too often | `talent-refresh` | The script isn't proven yet under the team's win criteria |
| A winning concept that only exists in one format | `format-variation` | The format is the reason it works. Check the audit first |
| Several ads with strong parts: one hook, another body, another CTA | `modular-remixing` | The parts don't share a persona or promise |
| Strong hook, weak conversion | Check congruency with the landing page first (`aca-ad-to-landing-page`). Then `modular-remixing` with a different body and CTA | |
| A winner where earlier small tweaks did nothing, or the platform treats versions as the same ad | `bigger-visual-swing` | |

## By what is cheap to make
Ask what exists before you recommend a shoot.

| We already have... | Cheapest plays |
|---|---|
| Unused footage or B-roll in `05-production/` | `fresh-b-roll`, `modular-remixing` |
| Hook variations that were filmed and never used | `new-hooks` |
| Creators in the tracker who agreed | `talent-refresh` |
| Only the finished ad | `format-variation` as a static through `aca-static-concept` |

## Which request type is it?
The four request types come from Chloe Rhys's sprint planning module (703).

| Request type | What it is |
|---|---|
| More | Iterate on a winner |
| Fix | A near-miss. Change one or two things |
| Adapt | Take a proven structure, angle or format (your own or another brand's) to a new product or persona |
| New | A net-new, untested concept |

- A winner gets a **More**: any play here.
- A near-miss gets a **Fix**: change one or two things, chosen by the symptom. Don't rebuild the whole ad.
- `new-hooks` aimed at a different persona, or `format-variation` and `modular-remixing` used to carry a proven structure to another product or persona, is an **Adapt**.
- If nothing in the ad is proven, it's a **New** concept, not an iteration.

## Rules for choosing
- Prefer the play that answers the symptom. Cheap comes second.
- For a true winner, the three-part winner playbook usually runs together: talent refresh, format variation, modular remixing.
- If two plays fit, propose both and let the strategist choose.
- If none fit, stop and ask. Don't invent a new play.
