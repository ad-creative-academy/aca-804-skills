# When to use each play

| If you see... | Choose | Not when... |
|---|---|---|
| A skeptical or provocative comment with lots of likes ("Natural deodorant doesn't work. Change my mind.") | `comment-response` | The comment is abusive or about a competitor by name |
| A vivid first-person review line for this persona | `customer-quote` | The line is a health or performance claim the brand can't make |
| Persona is unaware or problem aware, and they have a clear identity (nurse, cyclist, 4pm meeting) | `persona-callout` | The persona is vague ("women 25 to 45") |
| Problem aware, and the pain is embarrassing or specific (the 4pm arms-down moment) | `problem-first` | It would shame the viewer and not name a shared moment |
| Solution aware, and they believe a myth ("naturals never work") | `myth-bust` | The "myth" is a health topic (aluminum). Don't go there |
| There's a time-based story (the adjustment week, hour ten of a shift) | `day-by-day-proof` | There's no evidence for the timeline |

If two fit, write one hook from each. If none fit, ask. Don't invent a new play.
