# Brisa weekly summary (example one-path skill)

## Before you start, read
- `02-language/how-we-read-the-ad-account.md`
- The latest ad account export in `00-inbox/` (or the ad data connector)
- `03-research/audience/customer-voice.md`

## Steps
1. Use the last 7 days, compared with the 7 before.
2. Start with the North Star: starter-kit CPA against the $32 target.
3. What's working for prospecting (max 3), with the reason. Leave out retargeting.
4. What's tiring: any ad with frequency above 3.
5. The three best new customer quotes from the last 30 days (verbatim, with IDs).
6. What we should make next: 3 concepts (persona × angle × awareness level × ad type) with the evidence.
7. **Draft the message. Post to #growth only when the user asked for it.**

## Output rules
- Under 300 words. No tables (it has to read well in Slack).
- Plain language. Say "early signal" when it is one.

**Agents prepare. People approve.**

## Corrections log
- (example) Quotes only from reviews in the last 30 days.
